# Руководство по работе с прокси

## Текущая ситуация

**Прокси НЕ работает:**
```
Прокси: 45.11.125.162:9824
Статус: Connection refused ❌
```

**Причины:**
1. Прокси-сервер выключен
2. Нужно добавить ваш IP (103.249.134.114) в whitelist
3. Неправильные креденшелы

**Поэтому сейчас:** Скрипт работает БЕЗ прокси (напрямую)

## Как работает прокси

### Схема работы:

```
БЕЗ прокси:
Ваш компьютер (103.249.134.114)
    ↓ прямое подключение
Vimeo.com
Vimeo видит: 103.249.134.114 делает много запросов
Результат: может заблокировать/показать капчу

С прокси:
Ваш компьютер (103.249.134.114)
    ↓ зашифрованный туннель
Прокси сервер (45.11.125.162)
    ↓ от имени прокси
Vimeo.com
Vimeo видит: 45.11.125.162 делает запросы
Результат: не знает что это вы, не блокирует
```

### Зачем нужен прокси:

1. **Скрыть реальный IP** - Vimeo не знает кто делает запросы
2. **Обойти блокировки** - можно делать много запросов
3. **Обойти капчу** - меньше вероятность капчи
4. **Географические ограничения** - доступ из другой страны

## Проверка прокси

### Шаг 1: Проверить работает ли прокси

```bash
python test_proxy.py
```

Должны увидеть:
```
✓ Ваш реальный IP: 103.249.134.114
✓ IP через прокси: 45.11.125.162  (ДРУГОЙ IP!)
✓ Vimeo доступен через прокси
```

### Шаг 2: Если прокси не работает

**Возможные действия:**
1. Связаться с провайдером прокси
2. Добавить ваш IP (103.249.134.114) в whitelist
3. Проверить логин/пароль
4. Проверить что сервер запущен

## Как включить прокси в скрипте

### Вариант 1: Через расширение Chrome (рекомендуется)

Когда прокси заработает:

1. **Расширение уже создано:** `chrome_proxy_extension/`

2. **Протестировать:**
```bash
python download_with_proxy.py
```

3. **Интегрировать в основной скрипт:**
В `download_vimeo.py` изменить функцию `create_driver`:

```python
def create_driver(proxy_address=None):
    chrome_options = uc.ChromeOptions()
    chrome_options.headless = False
    chrome_options.add_argument('--ignore-certificate-errors')

    # Загружаем расширение для прокси
    extension_path = os.path.abspath("chrome_proxy_extension")
    chrome_options.add_argument(f'--load-extension={extension_path}')

    # Отключаем загрузку изображений
    prefs = {
        "profile.managed_default_content_settings.images": 2
    }
    chrome_options.add_experimental_option("prefs", prefs)

    driver = uc.Chrome(options=chrome_options, version_main=145, use_subprocess=True)
    logger.info("Chrome driver created with proxy extension")
    return driver
```

### Вариант 2: Через selenium-wire (Python 3.12 и ниже)

## FAQ

**В: Почему Chrome не поддерживает прокси напрямую?**
О: Chrome не поддерживает формат `user:pass@host:port` через аргументы командной строки. Только через расширения или системные настройки.

**В: Можно ли использовать другой прокси?**
О: Да! Измените креденшелы в:
- `chrome_proxy_extension/background.js`
- `test_proxy.py`

**В: Как узнать что прокси заблокирован?**
О: Запустите `python test_proxy.py` - увидите "Connection refused" или "Timeout"

**В: Нужен ли прокси для 694,343 видео?**
О: Очень рекомендуется! Без прокси высокий шанс блокировки после нескольких сотен запросов.
