# Простое объяснение ПРОКСИ

## 🤔 Что такое прокси простыми словами?

Представьте что вы хотите купить что-то в магазине, но не хотите чтобы продавец знал кто вы.

```
БЕЗ ПРОКСИ:
Вы идёте в магазин сами
Продавец видит вас и запоминает
Если придёте часто - может не пустить

С ПРОКСИ:
Вы отправляете друга в магазин
Продавец видит друга, а не вас
Можете приходить сколько угодно
```

В интернете:
- **ВЫ** = ваш компьютер (IP: 194.87.130.209)
- **МАГАЗИН** = Vimeo.com
- **ДРУГ** = прокси-сервер (IP: 45.11.125.162)

## 📊 Результаты проверки вашего прокси

### ✅ Что работает:
```
Ваш IP: 194.87.130.209 ✓
```

### ❌ Что НЕ работает:
```
Прокси: 45.11.125.162:9824 ✗
Статус: Connection refused (Отказано)
```

## 🔍 Что значит "Connection refused"?

**Простыми словами:**
Ваш компьютер позвонил прокси-серверу, но никто не ответил.

**Как будто:**
```
Вы звоните другу:      📞 → 🙍
Друг не берёт трубку:  📞 ← ❌ "Абонент недоступен"
```

**Технически:**
```
Ваш компьютер → 45.11.125.162:9824
                     ↓
            [Никто не отвечает]
                     ↓
            Connection refused ❌
```

## 🛠️ Как проверить прокси вручную

### Способ 1: Через Python (самый простой)

```bash
python check_proxy_simple.py
```

**Вы увидите:**
- ✅ Ваш IP (должен показать)
- ❌ или ✅ Прокси работает/не работает

### Способ 2: Через терминал (curl)

```bash
./test_proxy_manual.sh
```

**Вы увидите:**
- Ваш настоящий IP
- Попытку подключения к прокси
- Результат (работает или нет)

### Способ 3: Вручную в терминале

```bash
# Узнать свой IP
curl https://api.ipify.org

# Проверить прокси
curl --proxy http://Cf0rm2:y4XUAq@45.11.125.162:9824 https://api.ipify.org
```

**Если прокси работает:**
```
194.87.130.209  ← ваш IP
45.11.125.162   ← IP прокси (ДРУГОЙ!)
```

**Если НЕ работает:**
```
curl: (7) Failed to connect to 45.11.125.162 port 9824: Connection refused
```

## 💡 Что делать дальше?

### ❌ Если прокси НЕ работает (сейчас)

**Вариант 1: Исправить прокси**

Свяжитесь с провайдером прокси и скажите:
```
Мой IP: 194.87.130.209
Прокси: 45.11.125.162:9824
Ошибка: Connection refused

Возможно нужно:
1. Включить прокси-сервер
2. Добавить мой IP в whitelist
3. Проверить логин/пароль
```

**Вариант 2: Работать БЕЗ прокси (рекомендую)**

```bash
./run.sh
```

**Плюсы:**
- ✅ Работает прямо сейчас
- ✅ Проще настроить
- ✅ Подходит для тестирования (100-1000 видео)

**Минусы:**
- ⚠️ Vimeo видит ваш IP
- ⚠️ Может быть блокировка при большом количестве запросов
- ⚠️ Может показать капчу

### ✅ Когда прокси заработает

1. **Проверьте:**
   ```bash
   python check_proxy_simple.py
   ```

2. **Если видите:**
   ```
   ✅ ПРОКСИ РАБОТАЕТ!
   IP через прокси: 45.11.125.162
   ```

3. **Используйте:**
   ```bash
   python download_with_proxy.py
   ```

## ❓ Частые вопросы

**В: Почему прокси не работает?**
О: Прокси-сервер выключен или требует регистрации вашего IP

**В: Можно ли скачивать без прокси?**
О: Да! Скрипт работает. Прокси нужен только для больших объёмов

**В: Как узнать что прокси заработал?**
О: Запустите `python check_proxy_simple.py` - увидите "✅ ПРОКСИ РАБОТАЕТ"

**В: Нужен ли прокси для 100 видео?**
О: Нет, для тестирования прокси не нужен

**В: Что делать если видео не скачиваются?**
О: Проблема не в прокси. Проверьте логи: `tail -f download.log`
