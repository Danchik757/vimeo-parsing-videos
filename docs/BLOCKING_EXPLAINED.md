# Почему блокируют и как это обходить

## 🚨 Проблема: Два типа блокировок

Vimeo использует **ДВА уровня защиты**:

### Уровень 1: Обнаружение ботов (Bot Detection)
```
Vimeo проверяет:
- User-Agent (это Python или браузер?)
- JavaScript выполнение (есть ли настоящий движок?)
- Canvas/WebGL fingerprint (уникальный отпечаток браузера)
- Поведение мыши (двигается ли курсор?)
- Cloudflare Challenge (капча для ботов)
```

**Решение: Selenium + undetected-chromedriver**
- Выглядит как РЕАЛЬНЫЙ пользователь в Chrome
- Выполняет JavaScript
- Проходит Cloudflare проверки

---

### Уровень 2: Rate Limiting по IP (Блокировка по количеству запросов)
```
Vimeo считает запросы с ОДНОГО IP:
- 194.87.130.209 → запрос 1
- 194.87.130.209 → запрос 2
- 194.87.130.209 → запрос 3
- ...
- 194.87.130.209 → запрос 1000 ← БЛОКИРОВКА!

Вывод: "Один юзер делает слишком много запросов = БОТ"
```

**Решение: Ротирующий прокси (НЕ статический!)**

## ❌ Почему ОДИН прокси НЕ помогает

Ваш вопрос абсолютно правильный!

```
С одним статическим прокси:
- 45.11.125.162 → запрос 1
- 45.11.125.162 → запрос 2
- 45.11.125.162 → запрос 3
- ...
- 45.11.125.162 → запрос 1000 ← БЛОКИРОВКА!

Результат: ПРОКСИ попадёт в blacklist через те же 5 минут!
```

**Один статический прокси = Бесполезно для больших объёмов**

## ✅ Что ДЕЙСТВИТЕЛЬНО работает

### Вариант 1: Ротирующий прокси (Rotating Proxy Pool)

Профессиональные прокси-сервисы дают НЕ один IP, а **пул из тысяч IP адресов**:

```
Запрос 1   → Прокси выбирает: 45.11.125.162
Запрос 2   → Прокси выбирает: 45.11.125.163
Запрос 3   → Прокси выбирает: 45.11.125.164
Запрос 4   → Прокси выбирает: 45.11.130.100
...
Запрос 1000 → Прокси выбирает: 45.11.131.250

Vimeo видит:
- 45.11.125.162 сделал 1 запрос   ✓ норма
- 45.11.125.163 сделал 1 запрос   ✓ норма
- 45.11.125.164 сделал 1 запрос   ✓ норма
- ... (1000 разных IP, каждый по 1 запросу)

Вывод: "1000 разных пользователей, всё нормально"
```

**Типы ротирующих прокси:**

1. **Резидентные (Residential)**
   - IP реальных домашних пользователей
   - Vimeo НЕ МОЖЕТ их заблокировать (это реальные люди!)
   - Дорого ($5-15 за 1GB трафика)
   - Примеры: Bright Data, Smartproxy, Oxylabs

2. **Datacenter прокси**
   - IP дата-центров/серверов
   - Дёшево ($1-3 за 1GB)
   - Могут блокироваться, но их много
   - Хорошо работают если менять IP каждые 5-10 запросов

---

### Вариант 2: Медленное скачивание БЕЗ прокси

```
Стратегия:
- Делать паузы между запросами (30-60 секунд)
- Скачивать в определённые часы (ночью, когда меньше нагрузка)
- Останавливать скрипт при первых признаках капчи
- Менять свой IP через VPN или перезагрузку роутера

Реально для:
- 100-500 видео в день
- Тестирования
- Небольших задач

НЕ реально для:
- 694,343 видео (займёт месяцы)
- Непрерывной работы 24/7
```

## 🔍 Ваш текущий прокси: 45.11.125.162:9824

**Проблемы:**

1. ❌ **Один статический IP** - попадёт в blacklist так же быстро
2. ❌ **Connection refused** - сервер вообще не работает
3. ❌ **Нет ротации** - один и тот же IP для всех запросов

**Что с ним делать:**

Если это **ТЕСТОВЫЙ** прокси от провайдера:
- Попросите доступ к **rotating proxy pool**
- Спросите про **резидентные прокси**
- Или используйте их API для автоматической ротации

Если это **обычный HTTP прокси**:
- Он бесполезен для массового скачивания
- Годится только для разового обхода блокировки региона

## 🎯 Почему Selenium решает одну проблему, а не другую

### Что делает Selenium:

| Проблема | Selenium помогает? | Почему? |
|----------|-------------------|---------|
| Cloudflare блокирует Python скрипт | ✅ ДА | Использует реальный Chrome |
| JavaScript не выполняется | ✅ ДА | Полноценный браузер |
| Bot fingerprinting | ✅ ДА | undetected-chromedriver обходит |
| Слишком много запросов с одного IP | ❌ НЕТ | Это блокировка по IP, не по User-Agent |

### Что делает прокси (ротирующий):

| Проблема | Прокси помогает? | Почему? |
|----------|-----------------|---------|
| Cloudflare блокирует Python скрипт | ❌ НЕТ | Прокси только меняет IP |
| JavaScript не выполняется | ❌ НЕТ | Прокси не запускает JS |
| Слишком много запросов с одного IP | ✅ ДА | Каждый запрос с нового IP |
| Региональная блокировка | ✅ ДА | Можно выбрать страну прокси |

## 💡 Полная схема защиты

```
МАКСИМАЛЬНАЯ ЗАЩИТА = Selenium + Ротирующий прокси

    Ваш компьютер
         ↓
    [Selenium + Chrome]  ← обходит детект ботов
         ↓
    [Rotating Proxy Pool] ← меняет IP каждые N запросов
         ↓
      Vimeo.com

Vimeo видит:
✓ Реальный браузер (Selenium)
✓ Разные IP адреса (Proxy Pool)
✓ Нормальное поведение
```

## 🎯 Итог: Ответы на ваши вопросы

### Вопрос 1: Почему прокси не попадёт в blacklist?

**Короткий ответ:** ОДИН статический прокси попадёт в blacklist так же быстро! Вы правы.

**Правильный прокси:** Пул из тысяч IP с автоматической ротацией. Каждый IP делает 1-2 запроса = выглядит как разные пользователи.

### Вопрос 2: Зачем Selenium?

**Ответ:** Selenium обходит защиту от ботов (Cloudflare, fingerprinting). Он НЕ решает проблему блокировок по IP.

**Полная защита:** Selenium (обход детекта ботов) + Ротирующий прокси (обход rate limit)

## ❓ Как проверить что прокси РОТИРУЮЩИЙ?

Запросите у провайдера 5 раз подряд:
```bash
curl --proxy http://USER:PASS@HOST:PORT https://api.ipify.org
curl --proxy http://USER:PASS@HOST:PORT https://api.ipify.org
curl --proxy http://USER:PASS@HOST:PORT https://api.ipify.org
curl --proxy http://USER:PASS@HOST:PORT https://api.ipify.org
curl --proxy http://USER:PASS@HOST:PORT https://api.ipify.org
```

**Если IP РАЗНЫЕ каждый раз** → ✅ ротирующий прокси (ХОРОШО!)
**Если IP ОДИНАКОВЫЙ** → ❌ статический прокси (ПЛОХО для скрейпинга!)
