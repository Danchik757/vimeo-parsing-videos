## Технические детали

### 1. Почему нужно ждать 15 секунд?

```
0 сек: HTML загружен       ← Слишком рано! Кнопки нет!
   ↓
5 сек: CSS применён
   ↓
10 сек: JavaScript загружается
   ↓
15 сек: React компоненты отрендерены  ← Кнопка появилась!
   ↓
Кликаем на кнопку Download ✓
```

### 2. Как работает селектор кнопки?

```javascript
// Vimeo рендерит кнопку через React:
<button
  class="chakra-button css-1tvamtq"
  aria-label="Download button"  ← Этот атрибут ищем!
>
  <svg>...</svg>
  Download
</button>

// Наш код:
driver.find_element(By.CSS_SELECTOR, "button[aria-label='Download button']")
```

### 3. Почему Chrome не поддерживает прокси напрямую?

```
Формат прокси: user:pass@host:port

Chrome CLI аргумент:
  --proxy-server=http://Cf0rm2:y4XUAq@45.11.125.162:9824
                        ^^^^^^ ^^^^^^
                        Chrome НЕ понимает user:pass в URL
                        Безопасность: креденшелы в строке запуска видны всем

Решение:
  1. Расширение Chrome (background.js перехватывает и авторизуется)
  2. selenium-wire (прокси на уровне сетевого стека)
  3. Системный прокси (настройки OS)
```

## Как запустить

### Тест на 100 видео:
```bash
./run.sh
```

### Полный режим (все 694,343):
```bash
# Измените в config.json:
"test_mode": false

# Запустите:
./run.sh
```

### С прокси (когда заработает):
```bash
# 1. Проверить прокси:
python test_proxy.py

# 2. Протестировать:
python download_with_proxy.py

# 3. Интегрировать в основной скрипт
#    (см. PROXY_GUIDE.md)
```
